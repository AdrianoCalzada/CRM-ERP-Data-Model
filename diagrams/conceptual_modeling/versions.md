# Diagram Version History

## Peter Chen's ER Diagram

### v1: Structural Overview

This diagram presents the foundational entities and their relationships, complete with cardinalities, as derived from the initial business analysis. It provides a high-level structural view of the data model. Note that this type of diagram does not natively represent polymorphic relationships, which are documented separately.

![Entities and relationships](/out/diagrams/peter_chen_er_v1.svg)

### v2: Detailed Model

This second version enhances the previous diagram by incorporating the detailed attributes within each entity. The result is a comprehensive Entity-Relationship model, built using Peter Chen's notation, which offers a complete and granular view of the entire data structure.

![Entities with attributes and relationships](/out/diagrams/peter_chen_er_v2.svg)
